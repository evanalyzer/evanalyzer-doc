## What is EVAnalyzer?

EVAnalyzer is the Rust reimplementation of [ImageC](https://github.com/imagec) and the successor of the [EVAnalyzer ImageJ plugin](https://github.com/evanalyzer/evanalyzer-ij). It provides a high-performance image viewer combined with a fully configurable, multi-step analysis pipeline for fluorescence microscopy and high-content screening data.

## Key Features

| Feature | Description |
|---|---|
| **40+ file formats** | CZI, ND2, LIF, VSI, OME-TIFF, SLD, SCN, and more via [Bio-Formats](https://www.openmicroscopy.org/bio-formats/) |
| **Multi-channel viewer** | Per-channel brightness/contrast, visibility toggles, and colour assignment |
| **Z-stack & T-stack** | Intensity projections (Max, Min, Avg, Sum, Middle) or per-frame processing |
| **ROI annotation** | Rectangle, oval, and polygon regions of interest drawn directly on the image |
| **Analysis pipeline** | 30 composable processing steps from preprocessing to object classification |
| **Interactive charts** | Histogram, scatter, and spatial heatmap views over the results table |
| **bioimage.io import** | Import a published model's RDF and auto-configure an AI Segmentation step |
| **Multi-well plate layout** | Group images by well/plate for high-content screening experiments |
| **XLSX & R export** | Pipeline results exported per image, per well, or per object |
| **Scale bar & minimap** | Physical scale bar and navigator thumbnail overlay |
| **Cross-platform** | Linux, Windows, and macOS, with optional CUDA-accelerated AI builds |
