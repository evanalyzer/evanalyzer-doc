## What is EVAnalyzer?

EVAnalyzer is the Rust reimplementation of [ImageC](https://github.com/joda01/imagec) and the successor of the [EVAnalyzer ImageJ plugin](https://github.com/evanalyzer/evanalyzer-ij). It provides a high-performance image viewer combined with a fully configurable, multi-step analysis pipeline for fluorescence microscopy and high-content screening data. See [About](/about/) for the full history.

## Key Features

<CardGrid>
  <Card title="40+ file formats" icon="document">
    CZI, ND2, LIF, VSI, OME-TIFF, SLD, SCN, and more via [Bio-Formats](https://www.openmicroscopy.org/bio-formats/).
  </Card>
  <Card title="Multi-channel viewer" icon="magnifier">
    Per-channel brightness/contrast, visibility toggles, and colour assignment.
  </Card>
  <Card title="Z-stack & T-stack" icon="random">
    Intensity projections (Max, Min, Avg, Sum, Middle) or per-frame processing.
  </Card>
  <Card title="ROI annotation" icon="pencil">
    Rectangle, oval, and polygon regions of interest drawn directly on the image.
  </Card>
  <Card title="Analysis pipeline" icon="puzzle">
    30 composable [processing steps](/commands/overview/) from preprocessing to object classification.
  </Card>
  <Card title="Interactive charts" icon="star">
    [Histogram, scatter, and spatial heatmap](/guide/results/#charts) views over the results table.
  </Card>
  <Card title="bioimage.io import" icon="cloud-download">
    Import a [published model's RDF](/ai/bioimageio-import/) and auto-configure an AI Segmentation step.
  </Card>
  <Card title="Multi-well plate layout" icon="list-format">
    Group images by well/plate for high-content screening experiments.
  </Card>
  <Card title="CSV & XLSX export" icon="download">
    Pipeline results exported per image, per well, or per object.
  </Card>
  <Card title="Scale bar & minimap" icon="information">
    Physical scale bar and navigator thumbnail overlay.
  </Card>
  <Card title="Cross-platform" icon="laptop">
    Linux, Windows, and macOS, with [optional CUDA-accelerated](/getting-started/downloads/) AI builds.
  </Card>
</CardGrid>
