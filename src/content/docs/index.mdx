              return;

          return;

## What is EVAnalyzer?

EVAnalyzer is the next-generation successor to the original [EVAnalyzer ImageJ plugin](https://github.com/evanalyzer/evanalyzer-ij).
Rebuilt for modern workflows, it pairs a high-performance image viewer with a fully configurable, multi-step analysis pipeline builder.
While adaptable to any image format, EVAnalyzer is optimized for complex datasets, including fluorescence microscopy and high-content, whole-slide screening data.
Designed for scale, the platform efficiently batch-processes thousands of images simultaneously, storing all results in a structured local database for seamless export and downstream analysis.
See [About](/about/) for the full history.

## Key Features

<CardGrid>
  <Card title="Multiple pipelines" icon="puzzle">
    Create as many independent image processing [pipelines](/guide/pipelines/)
    as your experiment needs - one per channel, or chained together for complex
    multi-step workflows.
  </Card>
  <Card title="40+ file formats" icon="document">
    CZI, ND2, LIF, VSI, OME-TIFF, SLD, SCN, and more via
    [Bio-Formats](https://www.openmicroscopy.org/bio-formats/), with full
    multi-channel support out of the box.
  </Card>
  <Card title="Whole-slide image support" icon="bars">
    Large pyramidal, tiled whole-slide images are streamed and analysed [tile by
    tile](/fundamentals/image-formats/#big-images) automatically - no manual
    downsampling required.
  </Card>
  <Card title="Z-stacks & time-lapse" icon="random">
    Intensity projections (Max, Min, Avg, Sum, Middle) or per-frame processing
    across Z-stacks and time-lapse (T-stack) sequences.
  </Card>
  <Card title="Live multi-channel viewer" icon="magnifier">
    Per-channel brightness/contrast, visibility toggles, and colour assignment,
    with a live pipeline preview that updates as you tune each step.
  </Card>
  <Card title="Interactive charts & results database" icon="star">
    [Histogram, scatter, and spatial heatmap](/guide/results/#charts) views over
    results stored in a queryable local database, ready for grouping, filtering,
    and export.
  </Card>
  <Card title="Batch processing at scale" icon="rocket">
    Queue and process thousands of images unattended - the same pipeline runs
    consistently across an entire dataset, storing results as it goes.
  </Card>
  <Card title="Built in Rust" icon="setting">
    EVAnalyzer is written in [Rust](/about/) rather than Python, for native-code
    performance and memory safety across large batch runs.
  </Card>
  <Card title="Classical & AI segmentation" icon="cloud-download">
    Combine classical algorithms (Threshold, Watershed, Edge Detection) with
    AI-based object detection (Stardist, UNet, Cellpose) in the same pipeline -
    or [import a published bioimage.io model](/ai/bioimageio-import/) to
    auto-configure one.
  </Card>
  <Card title="Train your own AI classifiers" icon="pencil">
    Paint examples directly on your images and [train a Random Forest, k-NN, or
    neural-network pixel/object classifier](/ai/training/) in minutes - no
    external model or dataset required, ready to use as a pipeline step.
  </Card>
</CardGrid>
