## Project Templates

Full `.evatemplate` project templates - classes, plate settings and pipelines - ready to open with **EVA › Open…**, **EVA › New from template…** or **New project from a template…** on the Start page. Templates with example images come as a `.zip` too. See [Saving a Project as a Template](/guide/pipelines/#saving-a-project-as-a-template) for how these work.

<DownloadGallery category="template" />

## Modules

`.evamodule` [modules](/guide/modules/) - a set of steps bundled into one step with its own parameters, for any pipeline. Put the file into the `templates` folder of [EVAnalyzer's folder](/guide/settings/#where-evanalyzer-stores-its-data) (`~/.evanalyzer/templates` on Linux, `~/evanalyzer/templates` on macOS, `C:\Users\<name>\evanalyzer\templates` on Windows) and it shows up under **Modules** in the command picker of every project. See [Module library](/guide/modules/#module-library).
