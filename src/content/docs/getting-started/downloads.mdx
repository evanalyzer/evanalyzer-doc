<DownloadPicker />

:::tip[Not sure which to pick?]
If you don't have a dedicated NVIDIA GPU, choose **No CUDA** - the CPU build runs everywhere and AI segmentation still works, just slower. See [System Requirements](/getting-started/system-requirements/) for GPU/driver details, and [Installation](/getting-started/installation/) for how to extract and start the app once it's downloaded.
:::

:::note[Linux + CUDA is two files]
The Linux CUDA build is published as a two-part archive (`.7z.001` and `.7z.002`) because of GitHub's 2 GB file-size limit. Download both parts shown above into the same folder before extracting - see [Installation](/getting-started/installation/) for the extraction command.
:::

## VS Code Extension

The [EVAnalyzer File Support](/vscode/extension/) extension adds validation, autocomplete, and creation wizards for `.evapipe`, `.evaproj`, and `.evapt` files to VS Code.

:::caution[Not yet packaged]
This extension isn't published to the VS Code Marketplace or Open VSX yet, so there's no single-file download - see [VS Code Extension](/vscode/extension/#installation) for how to build and install it from source. Once a release is published, a direct download will replace this note.
:::

Track releases (or check for new ones) on the [repository's releases page](https://github.com/evanalyzer/evanalyzer-vscode/releases).
